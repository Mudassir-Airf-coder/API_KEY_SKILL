# API_KEYS_SKILL

> **One Skill. Any Agent. Instant Mastery over 1400+ Public APIs.**

---

## Vision

Modern AI coding agents are powerful, but they waste time and tokens searching for the right free API every time.

**API_KEYS_SKILL** solves this permanently.

We created a single, self-installing skill that turns **any coding agent** into an expert at discovering and using free public APIs. No more manual skill adding. No more repeating the same research.

### Why we built this

- Developers and autonomous agents constantly need weather, finance, crypto, maps, news, validation, entertainment and hundreds of other APIs.
- Searching Google or reading long lists every time is slow and expensive.
- Most agents forget useful APIs after one session.

This skill gives your agent **permanent knowledge + live search capability** over the famous [public-apis](https://github.com/public-apis/public-apis) collection (1400+ free APIs across 51 categories).

---

## One-Line Install (Works with any Agent)

Copy and paste this single line into **any** coding agent (Claude, Cursor, Windsurf, Continue, Aider, custom agents, etc.):

```text
Read and strictly follow the instructions in https://raw.githubusercontent.com/mudassirarfaarif-bot/API_KEYS_SKILL/main/AGENT.md
```

That is all.

The agent will automatically:
1. Load the skill
2. Understand the system
3. Become a master at finding and using free public APIs
4. Continue with your original task

---

## What the Agent Gains

- Instant knowledge of 51 categories of free APIs
- Ability to search live via `https://api.publicapis.org`
- Clear decision process: when to use which type of API
- Preference for free / no-auth APIs
- Clean patterns for calling APIs safely
