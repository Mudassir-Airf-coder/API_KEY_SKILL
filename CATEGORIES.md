# CATEGORIES.md — 51 Categories + Popular Free APIs

Below are all 51 categories from public-apis with **popular free / low-friction APIs** (3–4 line summaries).

Focus is on APIs that are free or have generous free tiers and are easy to use.

---

### Animals
- **Cat Facts** / **Dog Facts** / **RandomDog** / **RandomFox** — Random animal facts and images. No auth. Perfect for fun features and demos.
- **The Cat API** / **The Dog API** — High quality cat & dog images (apiKey free tier available).
- **PlaceDog / PlaceBear** — Placeholder animal images.

### Anime
- **AnimeChan** — Thousands of anime quotes. No auth.
- **Jikan** — Unofficial MyAnimeList API. Great for anime search and details.
- **Studio Ghibli API** — Free data about Ghibli films and characters.

### Anti-Malware
- **URLScan.io** / **VirusTotal** (limited free) — URL and file scanning.
- Prefer free tiers carefully; many have rate limits.

### Art & Design
- **Harvard Art Museums** / **Met Museum** — Open access art data and images.
- **Color APIs** and icon services available in this category.

### Authentication & Authorization
- Mostly paid or complex. Use only when necessary. Prefer free alternatives for simple needs.

### Blockchain
- **Etherscan**, **Covalent**, **The Graph** (free tiers) — On-chain data, balances, transactions.

### Books
- **Open Library** — Free book data, covers, search. No auth for many endpoints.
- **PoetryDB** — Poetry search. No auth.
- **Google Books** (apiKey free tier).

### Business
- Various company and business data APIs. Check free tiers carefully.

### Calendar
- Public holiday APIs and calendar utilities (many free).

### Cloud Storage & File Sharing
- Mostly require auth. Use only if needed.

### Continuous Integration
- Developer tooling APIs.

### Cryptocurrency
- **CoinGecko** — Excellent free crypto prices, market data, no key required for basic use.
- **CoinCap**, **CoinLore** — Free alternatives.
- Prefer these over paid services for most projects.

### Currency Exchange
- **ExchangeRate-API**, **Frankfurter**, **Exchangerate.host** — Free real-time and historical rates.

### Data Validation
- Email, phone, VAT, address validation APIs. Many have free tiers (Mailboxlayer, Numverify style).

### Development
- **JSONPlaceholder** — Fake REST API for testing. Perfect for prototypes.
- **ReqRes**, **httpbin**, **Postman Echo** — Testing endpoints.
- GitHub API (public data free with higher limits using token).

### Dictionaries
- Free dictionary and thesaurus APIs available.

### Documents & Productivity
- PDF, document generation and productivity tools (mixed free/paid).

### Email
- Validation and temporary email services (free tiers exist).

### Entertainment
- Jokes, quotes, trivia, movies (OMDb has free tier with key).

### Environment
- Air quality, climate, and environmental data APIs.

### Events
- Event discovery APIs.

### Finance
- Stock market data (many free tiers: Alpha Vantage, Finnhub, Yahoo-style unofficial).
- Prefer free tiers for personal and hackathon projects.

### Food & Drink
- Recipe and food related free APIs.

### Games & Comics
- Pokemon, comic, game data APIs (PokeAPI is excellent and free).

### Geocoding
- **Nominatim (OpenStreetMap)** — Free geocoding (respect usage policy).
- **Positionstack**, **OpenCage** (free tiers).

### Government
- Country, census, and open government data.

### Health
- Medical and health related open data (use carefully).

### Jobs
- Job board APIs (often require keys).

### Machine Learning
- Model and dataset related free endpoints.

### Music
- Lyrics, artist, and music metadata (some free).

### News
- **NewsAPI** (free tier), **GNews**, other free news aggregators.

### Open Data
- Large collection of open government and scientific datasets.

### Open Source Projects
- Project and repository related data.

### Patent
- Patent search APIs.

### Personality
- Quotes, advice, and personality test style APIs.

### Phone
- Phone number validation and lookup (Numverify style free tiers).

### Photography
- Unsplash, Pexels style free image APIs (keys usually required but free).

### Programming
- Language, documentation, and code related APIs.

### Science & Math
- NASA APIs (free key), math, space, and scientific data.

### Security
- Security related tools and scanners.

### Shopping
- Product and e-commerce data (limited free options).

### Social
- Social media related public endpoints.

### Sports & Fitness
- Sports scores and fitness data (many free or free-tier).

### Test Data
- Fake data generators (JSONPlaceholder, etc.).

### Text Analysis
- Sentiment, language detection (some free).

### Tracking
- Package and shipment tracking (usually keys).

### Transportation
- Public transport, flights (Aviationstack free tier), transit APIs.

### URL Shorteners
- Free URL shortening services.

### Vehicle
- Vehicle data and VIN related APIs.

### Video
- YouTube data (key required), other video metadata.

### Weather
- **Open-Meteo** — Completely free, no key, excellent.
- **WeatherAPI**, **OpenWeatherMap** (free tiers with key).
- Prefer Open-Meteo when possible.

---

**Tip**: Always verify current status with `https://api.publicapis.org/entries?category=CATEGORY` because free tiers and availability can change.
